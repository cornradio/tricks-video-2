FFmpeg 推荐必装

          
用在哪里：缩略图 / 封面、播放兼容转封装、视频页「转换画质」、提取 / 合并字幕、截片段与导出 GIF、时长探测（ffprobe）。没有它，浏览与播放会明显受限。

          
官网下载：ffmpeg.org/download.html

          

            
Windows（推荐 winget）

            

              winget install Gyan.FFmpeg
              
            

            
macOS（Homebrew）

            

              brew install ffmpeg
              
            

            
Linux（Debian / Ubuntu）

            

              sudo apt update && sudo apt install -y ffmpeg
              
            

          

          
装好后新开一个终端，执行 ffmpeg -version 能输出版本即表示 PATH 已就绪；然后重启本服务。

        


        

          
HandBrakeCLI 转换页需要

          
用在哪里：「转换」里的单集转换、文件夹转换、批量 MKV→MP4（含 MP4→MP4 修复）。不做转码可以不装；要用这些功能就必须装 HandBrakeCLI（命令行版，不只是图形界面）。

          
官网：handbrake.fr/downloads.php（选 Command Line / CLI）

          

            
Windows（winget，含 CLI）

            

              winget install HandBrake.HandBrake
              
            

            
Windows（Scoop，命令行版）

            

              scoop install handbrake-cli
              
            

            
若安装后终端找不到 HandBrakeCLI，把含 HandBrakeCLI.exe 的目录加入 PATH，重开终端后再试。

            
macOS（Homebrew）

            

              brew install handbrake
              
            

            
Linux（Debian / Ubuntu）

            

              sudo apt update && sudo apt install -y handbrake-cli
              
            

          

          
验证：执行 HandBrakeCLI --version（Linux 上也可能是 HandBrakeCLI / 包提供的同名命令）。通过后再重启本服务。
